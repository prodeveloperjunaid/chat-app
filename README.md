# 💬 ChitChat — Real-Time Full-Stack Messaging Application

ChitChat is a modern, responsive, real-time messaging web application built with React, Tailwind CSS v4, Formik, Yup, Node.js, Express, Socket.io, JWT Authentication, and MongoDB Atlas.

## 🚀 Live Demo
- **Live App**: [https://junaid-chat-app.vercel.app](https://junaid-chat-app.vercel.app)
- **GitHub Repository**: [https://github.com/prodeveloperjunaid/chat-app](https://github.com/prodeveloperjunaid/chat-app)

## ✨ Key Features
- **🔐 Secure JWT Authentication**: Passwords encrypted with `bcryptjs` + JWT Tokens (`jsonwebtoken`).
- **⚡ Real-Time WebSockets**: Instant 2-way messaging powered by `Socket.io`.
- **🍃 Cloud Database Persistence**: MongoDB Atlas cloud database for users and chat history.
- **📱 Fully Responsive**: Custom mobile & desktop layout with smooth sidebar navigation.
- **🎨 Clean Tailwind CSS v4**: Light aesthetic UI design with automatic smooth scrolling (`useRef`).
- **💾 Session Persistence**: Saved login state via `localStorage`.

## 🛠️ Tech Stack
- **Frontend**: React, Tailwind CSS (v4), Formik, Yup, Socket.io-Client, Vite
- **Backend**: Node.js, Express.js, Socket.io, Mongoose, Bcryptjs, JsonWebToken
- **Database**: MongoDB Atlas Cloud
- **Deployment**: Vercel Serverless & Render
